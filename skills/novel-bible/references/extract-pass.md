# 情節抽取

只根據原文與已驗證角色卡寫 bible。只輸出 JSON，不要解釋。

## 規則

- 時間線只記實際發生、有人參與的事，不寫氣氛評論。
- 關係必須是文本裡看得到的互動或稱謂，不要推論成完整家譜。
- 矛盾是同一事實的兩種說法，或前後不能同時成立的描述。找不到就留空陣列。
- 線索是尚未收回或已收回的伏筆。找不到就留空陣列。
- `evidence` 必須是原文連續片段，不得拼接、改寫或翻譯。
- `who` / `from` / `to` 只能使用 cast 裡的 name 或 aliases。

## 最小輸出

至少要有一條 timeline 或 relationship。短篇沒有明顯矛盾時，`contradictions` 應為 `[]`，不要編造。
