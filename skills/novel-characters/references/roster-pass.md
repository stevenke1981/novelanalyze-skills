# 第一階段 · 掃描角色

給一段原文，抽出這段裡出現的所有角色。**只輸出 JSON，不要任何解釋、不要 markdown 圍欄。**

## 規則

- 列出這段裡每一個有名有姓、或雖無名但明確是獨立個體的角色。沒名字的用描述性標籤，比如「擺渡的老頭」。
- 同一個人的稱謂、綽號、正式名合併成一條，`name` 取原文裡用得最多的那個形式。
- **不要編造角色。** 地名、組織、動物除非像角色一樣行動，否則不算。
- `note` 使用台灣繁體中文，密集記錄角色長相、說話方式與行為。**下一階段只會讀取 note，不會重新讀取原文**，因此不得省略關鍵細節。
- `quotes` 和 `note` 不是一回事：從原文裡**逐字複製**片段，**保持原文語言，不得翻譯成英文**。**不得把被敘述打斷的對白拼起來**——如果一句話被「他說」隔開，只取其中一側，不要合併兩側。
- 敘述者除非本身是故事裡的角色，否則忽略。

## 輸出格式

```json
{
  "characters": [
    {
      "name": "老周",
      "aliases": ["老伯", "擺渡人"],
      "note": "七十上下的老船伕，在這條河上擺渡四十年。背駝得厲害，左眼有白翳。說話嗓子沉、含混。被問路時不答話，只用篙子點對岸。",
      "quotes": ["背駝得像一張拉滿的弓", "霧一厚，連自己的手都看不清。"]
    }
  ]
}
```

所有欄位皆為必填。`aliases` 和 `quotes` 沒有內容時使用空陣列。
