# report.html 的設計約定

報告由 `scripts/novel-characters.mjs render --html` 生成，樣式全部內聯在 `renderHtml()` 裡。**改樣式只改那一處**，不要另起模板。

這份文件記錄為什麼長這樣，免得後來的改動把它改回一個通用的卡片牆。

## 它是什麼

不是行銷頁，而是**製作用的角色設定集**。讀者會直接使用這些提示詞製作圖片與配音。頁面的唯一任務是：**讓人快速找到正確提示詞，同時確認人物分析具有原文依據。**

所有設計決定都從這一句推出來。

## 三條不能破的規矩

### 1. 雙字域

中文印刷體本身就分工，直接用：

| 字型 | 語域 | 用在 |
| --- | --- | --- |
| **宋體** `--serif` | 敘事——關於故事的 | 書名、角色名、一句話、**故事摘要**、**原文引文** |
| **黑體** `--sans` | 分析——關於角色的 | 人物分析正文、欄位標籤、介面 |
| **等寬** `--mono` | 機器輸入 | 英文提示詞、序號 |

真正逐字來自原文的只有 `.source blockquote`。它額外帶有鐵鏽紅邊欄與「」引號；**這對引號是「此處為原文」的唯一標記**，不可用來裝飾摘要或一句話介紹。

這是這份報告跟任何一個角色卡生成器的區別所在，不要把它統一成一種字型。

全部用系統字型，**不得引外部字型**——報告要能離線雙擊開啟。

### 2. 不隱藏內容

**不要使用分頁、摺疊或「展開更多」。** 整頁必須能透過 Ctrl+F／Cmd+F 搜尋任何文字。

第一版使用三個分頁，畫面雖然簡潔，卻使搜尋、列印與快速瀏覽變得困難。工作文件不應隱藏內容。

### 3. 推斷標記要高亮

`（推斷）` 和 `(inferred)` 由 `marked()` 自動包成 `<span class="inf">`，帶淺鐵鏽紅底。

這是本報告的簽名細節。這個工具的核心承諾就是「哪些有原文依據、哪些是為了能用而補的」，把它做成視覺，比寫在文件裡有用。頁尾也有一句說明。

## 配色

冷灰印張 + 鐵鏽紅印記。**紅色只用在跟原文有關的地方**：引文的邊欄和引號、主角標籤、hover 態。別拿它當通用強調色。

| token | 淺色 | 用途 |
| --- | --- | --- |
| `--paper` | `#e9eae5` | 冷灰印張，不是暖奶油 |
| `--panel` | `#e1e3dd` | 提示詞塊 |
| `--ink` | `#191d21` | 藍黑，不是純黑 |
| `--seal` | `#8a3324` | 鐵鏽紅，只給原文 |

深色模式由 `prefers-color-scheme` 切換，**三視圖的印張永遠白底**——它是一張紙，不是 UI 面板。

## 尺寸與網格 ⚠️ 強制規格

- **頁面上限 1800px**（`.wrap{max-width:1800px}`）
- **一排最多三個角色**

「最多三個」不是寫死列數，是靠 `minmax` 卡出來的：

```css
.cast{grid-template-columns:repeat(auto-fit,minmax(460px,1fr));gap:28px}
```

1800 減去兩側 40 內邊距剩 1720：三列 `3×460+2×28=1436` 裝得下，四列 `4×460+3×28=1924` 裝不下。**這三個數（1800 / 460 / 28）是聯動的，改一個要重算另外兩個**，自測裡有斷言盯著。窄屏自然降到兩列、一列。

## 結構

```
角色設定集                                    ← eyebrow
《書名》· 角色                                 ← 宋體大標題
4 位角色 · 3 張三視圖 · 按戲份排序
════════════════════════════════════════════
┌── 故事摘要 ─────────┐  01 沈知微 ······ 主角   ← 摘要與目錄並排，
│ 民國年間的清晨…      │  02 陸行遠 ······ 主要     把 1800 的寬度用起來
└────────────────────┘  03 老周  ······· 主要
                        04 胡二爺 ······ 配角   ← 序號是排名不是裝飾：
                                                  按出現塊數排的戲份權重

┌─ 01 沈知微 主角 ──┐ ┌─ 02 陸行遠 ──┐ ┌─ 03 老周 ──┐
│ 一句話            │ │              │ │            │
│ [三視圖]          │ │ [三視圖]     │ │ [三視圖]   │
│ 人物分析          │ │ …            │ │ …          │
│  外貌 / ▍原文依據 │ │              │ │            │
│ 形象              │ │              │ │            │
│  [提示詞] 複製    │ │              │ │            │
│ 聲音              │ │              │ │            │
│  [提示詞] 複製    │ │              │ │            │
└──────────────────┘ └──────────────┘ └────────────┘
```

卡片內的三組內容（人物 / 形象 / 聲音）採**直向排列**，使用 `.groups{display:block}`。卡片寬度有限，不要再切分成多欄。

## 每段提示詞一個複製按鈕

不能少。目前每個角色 8 個：風格標籤、出圖 EN、出圖中文、反向、三視圖 EN、音色 EN、音色中文、整份 JSON。自測裡有斷言盯著這個數。

## 品質底線

- 支援手機回應式版面（三欄 `auto-fit` 自動縮成一欄）
- 鍵盤焦點可見（`.copy:focus-visible`）
- `prefers-reduced-motion` 關掉全部動效和平滑滾動
- `@media print` 隱藏按鈕和目錄、條目不跨頁斷
- 角色資料是模型生成的，**一律 `esc()` 轉義**後再拼進 HTML

## 動效

只有一處：目錄逐行漸顯（45ms 階梯）。其餘靠排版和留白，不靠動畫。
