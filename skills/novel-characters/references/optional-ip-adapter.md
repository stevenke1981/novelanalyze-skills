# 可選外部食譜：參考圖特徵鎖定

本技能**不安裝**、不依賴 IP-Adapter、InstantID、PuLID 或任何擴散模型權重。

若你自己的圖像後端已經有參考圖條件化，可以這樣對齊本技能的契約：

1. 只把核准的 `identity-board` PNG 當身份參考，權重設高。
2. 服裝板至少中高權重；不要用明星臉、演員臉或既有 IP 角色當捷徑。
3. 真人 sidecar 與漫畫 sidecar 的參考圖不可混用。
4. 生成後仍須跑 `audit`。檔頭、比例或身份雜湊失敗時標 `FAIL`，不要只看「有檔案」。

InstantID／人臉 ID 模型特別容易撞上禁止名人像的政策。沒有自建後端時，忽略本文件即可。
